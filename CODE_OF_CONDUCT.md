# Code of Conduct

## Our standard

We want a welcoming, constructive, and technically rigorous project. Participants
should be respectful, assume good intent, give actionable feedback, and make room
for different backgrounds and perspectives.

Unacceptable behavior includes harassment, discrimination, personal attacks,
deliberate intimidation, doxxing, sexualized conduct, and publishing private
information without permission.

## Enforcement

Report concerns privately to the repository maintainers through the security or
private contact channel configured in GitHub. Maintainers may clarify, remove,
reject, or restrict participation when behavior violates this code.
